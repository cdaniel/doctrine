# Doctrine

> ## 📦 This tool has moved
>
> The doctrine assessment tool has been **rebuilt as a framework-free web component** and now lives at **[doctrine2.kda.zone](https://doctrine2.kda.zone)**. This React version is archived, and `doctrine.wardleymaps.com` redirects to the new home.

It lives in [cdaniel/personal-presence-os](https://github.com/cdaniel/personal-presence-os).

---

A very simple tool for visualising how competitive is the company in the light of Simon Wardley's Doctrine.

You can navigate using ```Tab``` and use keys ```1```,```2``` & ```3``` to change your evaluation.
